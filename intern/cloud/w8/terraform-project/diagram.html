FLOW Step-by-step (build & use)

PHASE 1 BUILD it — one terraform apply

1

terraform apply

You run one command. Terraform creates everything below in order.

2

Build the network

VPC, 2 public subnets, internet gateway + route to 0.0.0.0/0.

VPC 10.0.0.0/162 subnetsIGW
3

Launch the EC2 server

Linux arm64 box, given a fixed public IP (Elastic IP) so it survives restarts.

t4g.mediumAL2023 arm64Elastic IP
4

Server sets itself up (on boot)

Installs Docker + socat, then starts a minikube Kubernetes cluster locally.

Dockersocatminikube
5

Create the load balancer

ALB listens on :80, forwards to the server on :30080 (health-checked).

6

Grab the cluster key

Terraform SSHes in, copies kubeconfig back to the laptop so it can talk to the cluster.

7

Deploy the app

Applies 2× nginx pods + a Service. HTML page & video ship inside a ConfigMap.

Deployment 2x nginx:1.27ConfigMap
✓

Done

Terraform prints the ALB URL — open it in a browser.

PHASE 2 USE it — a visitor opens the site

1

Visitor browser

Sends an HTTP request on port 80 to the ALB URL.

2

ALB receives it

Public load balancer accepts traffic on :80 from anywhere.

3

Forward to EC2

ALB sends the request to the server on port 30080.

4

socat relays inward

A small relay forwards :30080 from the host into the minikube cluster.

socat-app
5

Kubernetes Service

NodePort 30080 picks a healthy pod to handle it.

Service / NodePort
6

nginx pod serves

One of the 2 nginx pods returns index.html + yes_web.mp4.

▶

Video plays

Page loads in the browser and the video autoplays. Success.

SEQUENCE Provision lifecycle

Who talks to whom while the cluster is built — one terraform apply.

sequenceDiagram
    autonumber
    actor You as You (laptop)
    participant TF as Terraform
    participant AWS as AWS API
    participant EC2 as EC2 server
    participant MK as minikube

    You->>TF: terraform apply
    TF->>AWS: Create VPC, 2 subnets, IGW, route table
    TF->>AWS: Allocate Elastic IP (fixed public IP)
    TF->>AWS: Launch EC2 (user_data injects the EIP)
    AWS->>EC2: Boot + run cloud-init (once)
    EC2->>EC2: Install Docker + socat, add 2GB swap
    EC2->>MK: minikube start --apiserver-ips=EIP
    EC2->>EC2: socat-app :30080, socat-api :8443
    EC2->>EC2: Write kubeconfig.ext, touch READY
    TF->>AWS: Create ALB :80 + Target Group :30080 + attach EC2
    TF->>EC2: SSH: wait for READY, then scp kubeconfig
    EC2-->>TF: kubeconfig (server = EIP:8443)
    TF->>MK: Apply ConfigMap + Deployment (2x nginx) + Service
    MK-->>TF: Resources created
    TF-->>You: Outputs: ALB URL, EC2 IP, ssh command

SEQUENCE Live request

What happens on every page load.

sequenceDiagram
    autonumber
    actor V as Visitor
    participant ALB as ALB :80
    participant EC2 as EC2 host :30080
    participant SOC as socat relay
    participant SVC as K8s Service (NodePort 30080)
    participant POD as nginx pod (1 of 2)

    V->>ALB: HTTP GET / (port 80)
    ALB->>EC2: Forward to instance :30080
    EC2->>SOC: Hand off :30080
    SOC->>SVC: Into the minikube cluster
    SVC->>POD: Route to a healthy pod
    POD->>POD: Read index.html + yes_web.mp4 from ConfigMap
    POD-->>SVC: 200 OK + page/video
    SVC-->>SOC: response
    SOC-->>EC2: response
    EC2-->>ALB: response
    ALB-->>V: 200 OK (video autoplays)
